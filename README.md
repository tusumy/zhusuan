# 珠间 · 木算盘练习室

一个可以在手机上亲手拨珠的木头算盘。**不要求先心算出答案**：每拨一下，盘面数值才会变化。

## 功能

- 五档木算盘：万、千、百、十、个位，支持 0–99,999。
- 一上四下珠：上珠 5，下珠各 1。靠梁的珠子计数。
- 手机触摸、拖珠和点击拨珠，也支持键盘 Enter / 空格操作。
- 自由练习、撤销一步、清盘、珠子音效开关。
- 出题练习：入门、进退位、连环借位／进位。
- 练习时先自动摆好起始数字，只显示题目和**当前实际拨出的数**。点击检查后判定是否正确，答错不直接泄露结果；可分步请求提示。
- 无第三方依赖，不用账号，不收集数据，可离线打开本地 HTML 文件。

## 打开方式

直接下载仓库里的 index.html、style.css、app.js、favicon.svg 放在同一文件夹，用现代浏览器打开 index.html。

或使用 **GitHub Pages** 发布：

1. 仓库 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. Branch 选 main，文件夹选 /(root)，保存。
4. Pages 部署成功后可访问：https://tusumy.github.io/zhusuan/ 。

> 注意：将文件提交到仓库并不等于已经启用 GitHub Pages。网站地址只有在 Pages 部署成功后才生效。

## 怎么拨

横梁上方一颗珠子代表 5；下方四颗珠子各代表 1。上珠**往下**靠梁、下珠**往上**靠梁才会计数。

- 点击上珠：开／关 5。
- 点击下珠：拨到那颗珠子所对应的数量；点击已经靠梁的下珠，会退回到它之前的数量。
- 向横梁拖动珠子，也可以模拟实体拨珠。
- 练习题例如 196＋7：从起始盘面 196 出发，可以先给十位加1（满十继续进位），再从个位减3，直到算盘自己显示结果。
